# Demo Asset Policy

This directory is reserved for small, intentionally reviewed, license-safe
Vigil documentation assets. No live screenshot or demo video is committed for
v0.1 because the repository has no approved trained model bundle or
privacy-reviewed capture session.

Keep raw recordings, generated videos, benchmark dumps, and unreviewed images
under the ignored `artifacts/` directory. Before adding any asset here, record
its source, consent or license status, creation revision, and whether displayed
states and confidence values came from a genuine model run.

Do not add a synthetic or manually edited prediction image in a way that could
be mistaken for measured model behavior.
